# Pixel Nations — Monetization Strategy

Monetization plan that protects Pixel Nations from **crypto** and **pay-to-win** positioning.

**Main decision:** Validate the fantasy first. **Do not add payments** before product validation.

---

## What we will not do

| Never (positioning) | Never (mechanics) |
|---------------------|-------------------|
| NFT land sale | Sell better land |
| Crypto game | Sell more resources |
| Marketplace for land | Sell larger armies |
| Pay-to-win strategy | Sell faster production |
| Digital real estate pitch | Sell guaranteed rare regions |
| Token / wallet gating | Sell market advantage |

**Do not monetize by selling land as an asset.**  
**Do not sell power.**

---

## Core line

> **Players do not buy power. They build history.**

---

## What Pixel Nations should not be

- NFT land sale
- Crypto game
- Marketplace
- Pay-to-win strategy game
- Investment / yield product

Monetization must reinforce **founder identity** and **access to a living strategy world** — not financial speculation.

---

## Future monetization themes (post-validation)

After demo + waitlist + first tests, revenue may explore:

| Theme | Examples (non-exclusive) |
|-------|--------------------------|
| **Access** | Early era entry, season access (fair rules) |
| **Cosmetics** | Banners, map pins, founder visuals |
| **Identity** | Titles, records, chronicle entries |
| **Prestige** | Founder badge variants (no stats) |
| **Community / nation tools** | Nation page flair, alliance chronicles (cosmetic/social) |
| **Chronicles / history** | Exported records, era books |
| **Optional supporter packs** | See Founder Pack below |

All future SKUs require **anti-complexity** and **no power** review (`docs/PRODUCT_SIMPLICITY_DOCTRINE.md`).

---

## Recommended first paid experiment

### First Age Founder Pack

A **supporter** product — not a land sale.

**May include:**

- Founder badge (cosmetic)
- Cosmetic banner / profile frame
- Profile title (“First Age Founder”)
- Early access priority (queue fairness — not power)
- Name in early public records / chronicle
- Private dev updates / founder channel

**Must not include:**

- Gameplay advantage
- Paid land or tile reservation with power implications
- Stronger resources
- Military or economic boosts
- Exclusive rare regions with mechanical bonuses

Price and mechanics TBD only after **GREEN** user tests and waitlist signal.

## Phased roadmap

| Phase | Focus | Payments |
|-------|-------|----------|
| **1. Demo validation** | World Map v7, vertical slice, QA, user tests | **None** |
| **2. Waitlist / First Age** | Join the First Age, interest capture | **None** |
| **3. Founder Supporter Pack** | Optional cosmetic + access prestige | **First experiment** — supporter only |
| **4. Premium identity / cosmetics** | Deeper customization, no stats | Paid cosmetics |
| **5. Nation / community tools** | Social prestige, chronicles | Subscription or one-time — TBD |
| **6. Chronicles / history** | Era records, exports | Optional add-on |

Do not skip phases. No Phase 3 without Phase 1–2 evidence.

---

## Kill criteria for any monetization idea

Cut the idea if it:

- Sells power or land as an asset
- Requires crypto wallet
- Creates pay-to-win in PvP or economy
- Confuses testers (“is this NFT?”)
- Ships before vertical slice GREEN
- Needs backend + payments before waitlist signal

---

## Communication guidelines

| Say | Don’t say |
|-----|-----------|
| Founder, First Age, claim land | Mint, stake, asset |
| Early access, supporter | Whitelist sale, floor price |
| Chronicle, legacy, empire | ROI, yield, investment |
| Finite world, 10,000 lands | Digital real estate |

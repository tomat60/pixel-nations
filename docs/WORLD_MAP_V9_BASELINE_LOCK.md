# World Map v9 Baseline Lock

Status: accepted current visual baseline.

Date: 2026-06-17

## Decision

World Map v9 is the accepted visual direction for the current Pixel Nations public demo.

The world map should now be treated as an asset-backed living atlas, not a CSS/SVG/grid-first prototype board.

## Accepted baseline

The accepted direction includes:

- Aurelian Basin map asset as the dominant visual base.
- `/world` presenting a playable map that feels like a world, not a spreadsheet.
- Landing page using the same map direction as atmospheric world preview.
- Existing claim flow preserved.
- Smoke path preserved:
  land → dashboard → settlement → nation → empire.

## Product truth preserved

One land can begin an empire.

The current demo shows Sector A-01 / Aurelian Basin as the first playable frontier insiger world of 10,000 lands.

## Do not regress

Do not return to:

- grid-first world presentation,
- abstract pixel-grid hero as the main map promise,
- fake CSS/SVG terrain as the dominant map art,
- crypto/NFT/wallet/mint/pay-to-win visual language,
- decorative changes that weaken land claim clarity.

## Known limitation

The wide atlas/globe-style framing and the zoomed playable Aurelian Basin map are not geographically aligned perfectly yet.

This is accepted for the current demo because v9 was a visual-direction breakthrough, not a full cartographic alignment pass.

## Future v10 direction

A future v10 map pass may improve:

- atlas-to-sector geographic alignment,
- game-screen feeling over presentation-page feeling,
- deeper cartographic consistency,
- more natural relationship between world preview and playable sector.

Future v10 must preserve:

- asset-backed map direction,
- claim clarity,
- smoke path,
- simplicity: land → city → nation → empire.

## QA rule

Screenshot approval is not enough.

Manual review and user confusion override automated QA. A map pass is only accepted when the first impression feels like a world and the claim flow remains clear.

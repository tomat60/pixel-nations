# Pixel Nations — Final Product Target v1.0

Status: ACTIVE STRATEGY RAIL  
Purpose: define the first strong playable version Pixel Nations is working toward.

## One-sentence target

Pixel Nations is a premium web strategy game where one claimed land can grow into a settlement, city, nation, and empire through visible choices, territorial identity, and long-term strategic progression.

## Product promise

The player should feel:

1. This land is mine.
2. My first settlement changes the land.
3. My choices create a city identity.
4. My city connects to other lands through trade, alliances, pressure, and expansion.
5. My nation can become an empire.

The game must not feel like a static dashboard with labels. It must feel like a living strategic world, even while the first version stays simple.

## First final playable version

The first final playable version is not the full 10,000-land MMO. It is a polished strategic vertical slice that proves the core fantasy:

- claim one land
- found a settlement
- choose a city foundation path
- unlock a first production/resource identity
- establish a trade or alliance route
- form a nation-level identity
- see a credible path toward empire

## Required player experience

A first-time player should understand within five minutes:

- what Pixel Nations is
- what a land represents
- what they can do after claiming land
- why settlement matters
- how settlement leads toward nation and empire
- why returning later could be interesting

## Quality target

The demo should feel premium, restrained, and strategic. It should avoid clutter, cheap mobile-game UI, pay-to-win framing, crypto framing, and feature overload.

## Scope boundaries

Not required for the first final playable version:

- full multiplayer economy
- real-time war
- full AI simulation
- full 10,000-land live world
- crypto/NFT/wallet/token systems
- procedural content at scale
- final interactive globe/map system

Required before public confidence:

- clear objective spine
- clear post-claim path
- visible settlement progression
- meaningful first choices
- stable QA/reporting
- deployable public demo
- no obvious first-impression layout bugs

## Acceptance definition

The first final playable version is accepted only when:

- the complete land → settlement/city → nation → empire path is understandable
- at least one complete player arc is playable without explanation
- mechanical QA passes
- public QA passes
- manual UX review says the core loop is understandable
- visual debt is classified and not blocking the core promise

# Pixel Nations — World Map v8 Final Direction Lock

## Purpose

This document locks the final visual direction for World Map v8 before implementation.

It exists to prevent another vague map sprint.

Cursor must not invent the visual direction.

Cursor must implement this locked direction.

## Final Direction

World Map v8 should be:

> A beautiful living strategic atlas where playable land is hidden inside a world worth entering.

The map must not feel like a grid with decoration.

It must feel like a world first, with land selection as a natural layer inside that world.

## Direction Mix

World Map v8 should follow this visual mix:

### 70% Living Atlas

The main base.

The map should feel like a premium atlas:
- believable geography
- terrain depth
- region identity
- natural borders
- subtle cartographic feeling
- calm beauty
- world-first impreion

The user should first think:

> I want to enter this world.

Not:

> I see a grid.

### 20% Cinematic Frontier

The emotional boost.

Aurelian Basin should feel like the first living frontier:
- atmospheric light
- subtle mystery
- sense of discovery
- first claim as a meaningful moment
- land that feels like the beginning of history

The user should feel:

> Something important can begin here.

Not:

> I clicked a cell.

### 10% Grand Strategy Atlas

The clarity and veteran-respect layer.

The map should imply future strategic depth:
- borders
- territory
- political identity
- future nations
- regional control
- long-term empire potential

The user should sense:

> This simple first step could grow into serious strategy.

But the map must not become too heavy, political, or data-dense too early.

## What This Means in Practice

### World First

The first impression must be terrain, region, atmosphere, and place.

The grid must be secondary.

### Land Selection Second

Clickable land must remain clear, but it should feel embedded in geography.

Tiles must support the world, not dominate it.

### UI Third

Panels and copy should guide the player, not compete with the map.

The UI should feel like a command layer over a living atlas.

### Data Last

Do not turn v8 into a system-heavy map mode.

Do not introduce strategy data overlays yet.

## Aurelian Basin Direction

Aurelian Basin is the first playable frontier.

It should feel like a real place within the larger 10,000-land world.

It needs:
- recognizable region identity
- terrain variation
- subtle frontier atmosphere
- land that feels claimable but natural
- selected land as a story moment
- clear Sector A-01 framing

Preferred framing:

> Aurelian Basin · Sector A-01  
> First playable frontier

Avoid making A-01 feel like:
- a chess coordinate
- a spreadsheet label
- the entire world
- a random sample grid

## First Claim Feeling

Claiming land should feel like a small ceremony.

Not a casino reward.

Not a form submission.

Not a spreadsheet update.

It should quietly say:

> History begins here.

Possible implementation cues:
- soft light
- subtle civic marker
- calm selected-land glow
- restrained animation
- short emotional confirmation
- no loud particle explosion

## Visual Do

Use:
- terrain-led map composition
- subdued tile boundaries
- atmospheric depth
- restrained ownership states
- subtle borders
- warm civilization accents
- premium dark UI frame
- clear CTA hierarchy
- mobile-safe layout

## Visual Do Not

Avoid:
- loud grid
- spreadsheet cells
- random land blobs
- crypto land-board energy
- neon ownersip colors
- heavy political map too early
- too many labels
- generic beige parchment fantasy
- admin-dashboard feeling
- hover scaling that causes layout movement
- animation that feels cheap or distracting

## Acceptance Gate

World Map v8 may proceed only if the implementation follows this lock.

A version fails if:
- it still feels grid-first
- it feels like a crypto land board
- it becomes too political too early
- it looks like a better prototype but not a stronger w it harms the smoke path
- mobile becomes confusing
- the user reaction remains: “the map still does not feel good”

## Success Definition

World Map v8 succeeds if:

- the first impression is a world, not a grid
- Aurelian Basin feels like a real first frontier
- land selection is clear but not visually dominant
- claiming land feels emotionally meaningful
- beginners feel visual curiosity
- strategy veterans sense future depth
- the existing demo path still works
- mobile remains usable

The target is not:

> better tiles

The target is:

> a stronger world.

# World Map v9 Acceptance Note

Status: accepted as the first strong visual direction for the Pixel Nations world map.

Decision:
World Map v9 uses a painted Aurelian Basin map asset as the dominant visual base, with the existing clickable land overlay preserved for the claim flow.

Why accepted:
- The first impression finally reads as a world/map, not a prototype grid.
- The playable sector now has atmosphere and strategic fantasy.
- The land → settlement → nation → empire smoke path remains intact.
- The current result is strong enough for the public demo direction.

Known limitation:
The wide atlas/globe-style framing and the zoomed playable Aurelian Basin map are not geographically aligned perfectly yet. This is accepted for the current demo because the work was a visual-direction breakthrough, not a full cartographic/mechanics alignment pass.

Futu direction:
- Align atlas framing and playable-sector geography more convincingly.
- Preserve the asset-backed direction.
- Avoid returning to grid-first CSS/SVG map visuals.
- Keep land claim clarity and smoke path above decorative accuracy.

Do not treat v9 as final production art. Treat it as the accepted visual direction and prototype implementation base.

# World Map Art Direction Brief

## Goal

The Pixel Nations map should feel like a premium strategic fantasy world where one land can begin the path to an empire.

It must not feel like:
- a spreadsheet
- a generic grid editor
- a crypto land-sale board
- a toy prototype map
- a decorative background without gameplay meaning

## Core Fantasy

The player is not just clicking a tile. The player is claiming the first piece of a future civilization.

The map must support this sequence:

land → settlement/city → nation → empire

## World Structure

Pixel Nations has a full world of 10,000 lands.

The current demo shows the first playable frontier, currently explained as:
- Aurelian Basin
- first playable sector
- sector code: A-01

A-01 is a sector code, not a chess-style coordinate that must visually match a precise spot on the atlas.

## Visual Direction

The map should feel like:
- premium strategic fantasy
- living caphy
- a frontier opening inside a larger world
- readable gameplay surface
- atmospheric but not cluttered

## Must Have

- clear distinction between full world and playable frontier
- believable continent or landmass shapes
- terrain rhythm: water, land, ranges, basins, routes
- ownership states that are readable but subdued
- selected land state that is clear without layout shift
- claimable lands that feel part of a world, not isolated buttons
- strong map frame and hierarchy
- mobile-safe interaction

## Avoid

- spreadsheet/grid-first impression
- fake crypto/NFT land board feeling
- over-bright ownership colors
- random continent blobs
- visual noise that hides interaction
- hover/selected scale that breaks layout
- huge pulses or arcade effects
- decorative elements that do not support gameplay clarity

## Sector / Atlas Relationship

The atlas should communicate the larger 10,000-land world.

The playable sector should communicate:
- this is the first frontier window
- this is where the player can act now
- the rest of the world exists but is not yet playable in the demo

The relationship must be understandable without explanation from the creator.

## Future Reference Research

Before World Map v8, prepare a reference board covering:
- premium fantasy strategy maps
- historical atlas layouts
- region maps from grand strategy games
- readable hex/tile strategy maps
- parchment/ink/cartographic UI examples
- modern premium game dashboard maps

References are for direction, not copying.

## Implementation Boundary

World Map v8 should not start until this brief is paired with:
- a reference board
- a visual acceptance rubric
- clear rejected patterns from v1–v7
- exact implementation scope

The goal is not “more detail.”

The goal is:
a believable, clickable world that makes claiming land feel like the beginning of history.

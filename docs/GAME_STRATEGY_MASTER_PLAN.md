# Pixel Nations — Game Strategy Master Plan v1.0

Status: ACTIVE STRATEGY RAIL  
Purpose: preserve the creative/product strategy so implementation does not drift.

## Core truth

One land can become an empire.

Everything in Pixel Nations should reinforce that promise.

## Strategic genre position

Pixel Nations should combine:

- the territorial ambition of grand strategy
- the approachable first-step clarity of modern web products
- the emotional ownership of claiming a place
- the long-term fantasy of civilization growth
- the visual premium of a living world map

Inspirations may include civilization builders, map strategy games, city builders, and nation-management games, but Pixel Nations must not become a clone. The differentiator is land identity evolving into political power.

## Product pillars

### 1. Land identity

Every meaningful journey starts with a land. A land is not just a tile; it is the seed of a future polity.

### 2. Visible growth

Progress should be visible in UI, state, copy, and eventually map presentation. The player should see that choices matter.

### 3. Strategic clarity before depth

The first demo must be understandable before it becomes deep. Complexity is earned only after the player understands the path.

### 4. Choice with consequence

Choices should shape the identity of a settlement/city/nation. The first version can use simple choices, but they must imply future consequence.

### 5. Premium restraint

No noisy menus, no manipulative monetization, no cheap reward spam, no crypto framing unless explicitly reopened.

## Core loop target

The demo loop should become:

1. Enter world.
2. Understand Sector A-01 as the playable basin.
3. Claim or inspect land.
4. Enter command center.
5. Found settlement.
6. Choose first development direction.
7. See next strategic milestone.
8. Understand nation/empire path.

## Map strategy

The map is important, but it is not the whole game.

Current rule:

- do not rebuild the full map/globe system until the core game loop is stronger
- fix only first-impression layout bugs or severe clarity blockers
- treat geography mismatch as visual debt unless it blocks the player path
- do not allow map polish to consume core-loop production time

## Monetization strategy guardrail

Current direction avoids crypto, NFT, wallet, mint, token, and pay-to-win. Monetization ideas can be preserved as future research, but not implemented until product, legal, and regulatory review.

## First strategic success metric

A new player should say:

“I claimed a land, I know what to build next, and I can imagine how this could become a nation.”

If that is not true, the next sprint should improve core-loop clarity before adding deep systems.
